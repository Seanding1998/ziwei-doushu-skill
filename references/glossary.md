## 1. 排盘公式（脚本已实现，此处仅供复核）

**命宫 / 身宫**
```
月宫 = 寅起正月，顺数至生月
命宫 = 月宫 − 时序号（逆数）       时序号：子0 丑1 … 亥11
身宫 = 月宫 + 时序号（顺数）
自检：身宫只能落在 命/夫/财/迁/官/福 六宫之一
```

**五行局**：由**命宫宫干纳音**定。
```
五虎遁（起五行寅例）：甲己起丙寅、乙庚起戊寅、丙辛起庚寅、丁壬起壬寅、戊癸起甲寅
命宫干支 → 六十甲子纳音 → 水二/木三/金四/土五/火六局
⚠️ 不可用「生年干顺数到生月查月支纳音」，更不可拿日柱查（这是常见根错）
```

**局数定紫微（对五局全部成立）**
```
商 = 日数 / 局数（取整）；余 = 日数 % 局数
余 = 0 → 自寅宫顺数 商 位 → 紫微
余 ≠ 0 → 自寅宫顺数 (商 + 局数 − 余 + 1) 位 → 紫微
核验值：水二局十五=申｜木三局十五=午｜金四局十五=辰｜土五局十五=辰｜火六局十五=丑
⚠️ 维基文库卷二「木三局 / 金四局」星格是转录已损坏的 nowiki 字符表，不可单独作依据
```

**起运**：虚岁 = 五行局数；每十年一大限。

**大限方向**
- 软件通行口径：自命宫起，阳男阴女顺行、阴男阳女逆行
- 古籍卷二：阳男阴女从**命前一宫（父母）**起顺行；阴男阳女从**命后一宫（兄弟）**起逆行
- 十八飞星本：阳男阴女从命宫顺数；阴男阳女从申宫逆数

**小限**：不论阴阳，**男顺女逆**；起点由生年支三合局定
```
寅午戌年 → 起辰宫 ｜ 申子辰年 → 起戌宫
巳酉丑年 → 起未宫 ｜ 亥卯未年 → 起丑宫
```
**童限**：1岁命宫、2岁财帛、3岁疾厄、4岁夫妻、5岁福德、6岁官禄，之后顺行，15 岁回命宫。

**流年命宫**：自生年支起，顺行一宫一年。

**真太阳时**
```
校正量 = (出生地经度 − 120) × 4 分钟 + 均时差
均时差（近似，±20 秒级）：
  γ = 2π/365 × (n − 1 + (h − 12)/24)      n = 年内第几天，h = 当地钟点
  EoT = 229.18 × (0.000075 + 0.001868cosγ − 0.032077sinγ
                  − 0.014615cos2γ − 0.040849sin2γ)   单位：分钟
```
⚠️ 与大寒/小寒期间的八字月柱无关；本校正**只移动时辰，不改节气**。

**时序号（iztro）**：0=早子(00:00–00:59) 1=丑 2=寅 3=卯 4=辰 5=巳 6=午 7=未 8=申 9=酉 10=戌 11=亥 12=晚子(23:00–23:59)。
23:00 整点属子时；晚子时按**次日**子时定时柱，日柱口径需确认。

## 2. 十二宫逆布次序（自命宫起）

```
命宫 → 兄弟 → 夫妻 → 子女 → 财帛 → 疾厄
     → 迁移 → 交友(仆役) → 官禄 → 田宅 → 福德 → 父母
```

**三方四正**：本宫 + 对宫（+6）+ 两个三合宫（+4、+8）。
**地支三合**：申子辰／寅午戌／巳酉丑／亥卯未。**六冲**：子午、丑未、寅申、卯酉、辰戌、巳亥。

**身宫落的六宫含义**（现代派归纳）：命宫=自我中心｜夫妻=以情感为重心｜财帛=经济驱动务实｜迁移=以外在机遇为方向｜官禄=以事业成就为追求｜福德=重精神世界。

## 3. 术语表

| 术语 | 含义 |
|---|---|
| 庙旺利陷 | 亮度分级；七级制：庙/旺/得地/利益/平和/不得地/落陷 |
| 生年四化 | 由生年干定的禄权科忌，一生不变（「出厂设定」） |
| 离心自化 ↓ | 本宫宫干把四化化入本宫内的星 |
| 向心自化 ↑ | 对宫宫干把四化化入本宫内的星 |
| 自化 | 以上两者统称；核心含义「**明有实无**」 |
| 禄转忌 / 忌转忌 | 飞星/钦天派追踪四化流转的手法，纲领「禄因，忌果」 |
| 来因宫 | 生年干所在宫；飞星/钦天派概念，**古籍无** |
| 夹宫 | 相邻两宫对本宫的夹制；吉夹吉、凶夹凶 |
| 朝 / 冲 / 拱 / 夹 / 坐 / 踞 / 协 / 胁 | 古籍论宫位关系的八个术语 |
| 三合共振 | 生年/大限/流年三层四化同星同向，能量最强 |
| 叠宫 | 大限或流年宫位落回本命某一宫 |
| 引动 | 静态存在的徵验需靠大限/流年煞忌触发才克应 |
| 空宫 | 该宫无十四主星；借对宫看，但力度打折 |
| 孤君在野 | 紫微无辅弼，主清贵而不掌实权 |
| 百官朝拱 | 紫微得十八吉曜齐会（王亭之核心为「八骏」） |
| 天罗地网 | 辰戌为天罗地网，紫微天相同宫落此 |
| 命身同宫 | 命宫与身宫同宫；先后天指向一致 |
| 斗君 | 流年正月的定位基准（子年斗君等） |
| 童限 | 15 岁前的辅助小限 |

## 4. iztro 2.6.2 API 备忘（脚本已用到的部分）

```js
const { astro } = require('iztro');

// 排盘
astro.astrolabeBySolarDate('1990-6-7', 4, '男', true, 'zh-CN')
//   参数: 公历日期, 时辰序号0-12, 性别, 是否修正闰月, 语言
astro.astrolabeByLunarDate('1998-1-2', 6, '男', false, true, 'zh-CN')

// astrolabe 常用字段
a.solarDate a.lunarDate a.chineseDate          // 四柱（农历年口径）
a.fiveElementsClass                            // 五行局
a.soul a.body                                  // 命主 身主
a.earthlyBranchOfSoulPalace / ...OfBodyPalace  // 命宫/身宫地支
a.palaces[]                                    // 十二宫
a.decadalList()                                // ⚠️ 是函数，不是属性

// 宫对象
p.name p.heavenlyStem p.earthlyBranch p.isBodyPalace
p.majorStars[] p.minorStars[] p.adjectiveStars[]   // {name, brightness, mutagen}
p.changsheng12 p.boshi12 p.suiqian12 p.jiangqian12
p.decadal.range

// 运限
const h = a.horoscope(new Date('2026-06-15T12:00:00'));
h.age.nominalAge h.age.earthlyBranch        // 小限
h.decadal.heavenlyStem/.earthlyBranch/.mutagen[]/.palaceNames[]/.stars[][]
h.yearly.…  h.monthly.…  h.daily.…  h.hourly.…
// ⚠️ decadal.stars / yearly.stars 是「按宫分组的嵌套数组」，需按 palaceNames 索引展开

// ⚠️ a.palace(index) 的索引口径易错，建议一律用 a.palaces.find(p => p.earthlyBranch === b)
```

## 5. 依赖与信任

- 依赖：`iztro@2.6.2`（npm，MIT），装在本 skill 的 `node_modules/`，**不装全局、不装进工作区**。
- 脚本全部为本地纯计算，**不联网、不读工作区外文件**（仅 `dump.js --file` 会读你指定的文件）。
- `ensure-deps.*` 会执行 `npm install`（联网）。首次使用前请知悉；受限网络下会依次尝试默认缓存 → skill 内本地缓存 → 显式代理 `127.0.0.1:7897`。
