# 紫微斗数：Codex 入口

本入口供 Codex 从仓库的 `.agents/skills/` 发现技能。完整工作流与规则以[仓库根目录 SKILL.md](../../../SKILL.md)为唯一维护来源；使用本技能时，先完整阅读该文件并严格执行，不用本入口代替原工作流。

## 定位与执行

- 以本入口所在目录为基准，向上三级即仓库根目录；不依赖当前工作目录或固定的检出路径。
- 根目录工作流中的 `scripts/`、`references/`、`examples/`、`requirements.txt` 和 `package.json` 均相对于仓库根目录，命令也在仓库根目录执行，不在本入口目录执行。
- 使用当前检出目录与已有依赖；先运行 `python scripts/ziwei.py engines` 检查引擎。若项目使用虚拟环境，先激活该环境；仅在依赖缺失时按根目录工作流准备依赖。
- 这是依赖当前仓库的入口；单独复制本目录不能替代完整仓库。移动完整仓库后，上述相对链接仍然有效。

## 原工作流导航

按根目录工作流顺序收集输入、准备依赖、调用真实排盘脚本、检查口径冲突、定盘、分析并生成报告。所有可计算事实来自脚本输出；转述全部告警，不自行推导星曜或四化，也不把格局构成条件直接视为成格。

按需阅读下列原始文件，不另建或修改一套规则：

- [解盘规则](../../../references/interpretation.md)：解盘前必读，包括定盘等级、九步顺序、流派分歧与判断边界。
- [报告数据定义](../../../references/report-schema.md)：生成报告前必读，先完成分析留痕，再成文和裁断格局。
- [报告模板与边界](../../../references/report-template.md)：报告措辞、口径声明、免责声明与交付清单。
- [独立审查流程](../../../references/review-gate.md)：交付报告前执行；按原要求隔离审查上下文，只提供盘面数据和成品报告。

AI 产出结构化分析，由 `scripts/generate_report.py` 渲染 HTML。交付前执行原工作流的字段校验、成品语言检查、盘面一致性审查与独立审查，并按要求运行审查器及语言规则自测。检查失败时按原工作流处理，不跳过、放宽或修改验证规则。

本入口只适配 Codex 的技能发现与路径定位，不改变原有排盘算法、依赖、定盘规则、验证规则或专业建议边界。
